Kaya bundles its existing variable fonts so builds and local use work offline.

- Inter: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/inter), `Inter[opsz,wght].ttf`, weights 100–900.
- Source Serif 4: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/sourceserif4), `SourceSerif4[opsz,wght].ttf`, weights 200–900.

Downloaded 14 October 2026. The files retain their optical-size axes and full character coverage. Their unmodified SIL Open Font Licences are included beside them. The two font files total approximately 2 MB and are served locally by Next.js with its static asset caching.
