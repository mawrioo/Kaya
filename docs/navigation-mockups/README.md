# Phone navigation concepts — 29 Oct 2026

Visual mockups for owner review. These do not change the running Kaya app.

- **Option 1:** a two-column menu attached below the top bar, with all seven pages and Settings. Quick add keeps its bottom strip.
- **Option 2:** Home, Transactions, Wallets and More in a persistent bottom bar. More opens Goals, Categories, Insights, Pet and Settings. A small Quick add button sits above the bar and hides while More is open.

Both use the same 390 × 844 Goals screen with illustrative figures and Kaya's bundled fonts. The figures are invented for comparison; no database was read.

- [Menus open, side by side](menus-open.png)
- [Page view, side by side](page-view.png)
- [Interactive mockup](index.html) — open in a browser, then use Menu / More, tap outside or press Escape. The controls above the phones switch both previews together. Other buttons show a preview message; they do not perform real actions.

The HTML embeds its fonts and needs no server or internet connection. Chromium rendering, menu toggles, dismissal and a narrow browser width were checked. A temporary static server was stopped after rendering. Physical phone usability and production navigation are outside this mockup review.

The owner selected option 2 and authorised the smaller bar plus assistant simplification. See [delivery and verification](../mobile-compact/SIMPLE-NAV-ENTRY.md). These images remain the original concept comparison.
